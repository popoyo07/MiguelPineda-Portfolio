Dream Punk

Dream Punk is a first-person puzzle game developed in 10 days using Unreal Engine. The project focused on environmental puzzles, player interaction systems, and fast gameplay iteration through Blueprint scripting.

Main Contribution

Technical Designer & Blueprint Programmer

My main contribution focused on gameplay scripting and puzzle interaction systems using Unreal Engine Blueprints. I worked on gameplay logic, player interactions, debugging, and rapid iteration during development.

Since the project had a short production window, Blueprint scripting allowed systems to be quickly prototyped, tested, and adjusted without slowing down iteration.

Additional Blueprint Systems

For one of the levels, I had to create security cameras that would automatically make the player lose if they interact with them. For it I created a version of the camera that only stays static looking at one location and then created a child from that one to rotate side to side to make the game feel more alive.

What I Learned

This project helped me improve my Unreal Engine Blueprint workflow and rapid gameplay prototyping skills.

Working under a short deadline taught me how to prioritize gameplay iteration and quickly debug Blueprint systems. The project also reinforced the importance of clear gameplay feedback and modular interaction logic when building puzzle-focused experiences.
